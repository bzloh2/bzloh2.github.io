# Brian Loh - Personal Portfolio Website

This repository contains the source code for my personal portfolio website, showcasing my professional career, technical skills, and projects as a Growth Software Engineer.

## 🌐 Live Website
Check out the live website at: [bzloh2.github.io](https://bzloh2.github.io)

## 🛠️ Technologies
- **HTML5** & **CSS3**: Clean, responsive layout with modern alternating sections and custom styles.
- **JavaScript**: Smooth scrolling navigation and dynamic scroll-fade entry animations.

## 🚀 Setup & Local Preview
To preview the website locally:
1. Clone the repository.
2. Serve the directory locally:
   ```bash
   python3 -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
