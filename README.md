## 💡 About the Site
This portfolio serves as a centralized hub to showcase professional experience building scalable web applications, executing A/B tests, managing AWS cloud infrastructure, and optimizing user onboarding flows. 

---

## 🏗️ Website Structure
The website consists of the following key sections:
1. **Hero Header**: A premium gradient header introducing Brian as a Growth Software Engineer in New York City.
2. **About Me**: A fluid overview of Brian's software engineering background and growth focus.
3. **Professional Experience**: A chronological timeline detailing software engineering impact at **Meta**, **Capital One**, **The Comic Book Hideout**, and **Epic Systems**.
4. **Education**: Underlining academic credentials from the **University of Illinois at Urbana-Champaign** (B.S. in Computer Science).
5. **Skills Inventory**: Grid-based breakdown categorized into *Frontend*, *Growth Engineering*, *Full Stack*, and *AWS & DevOps*.
6. **Call to Action**: High-conversion contact widgets for direct email and phone connections.

## 🛠️ Technologies & Design System
This portfolio is built with lightweight, modern, and standard web technologies to achieve fast page loads and smooth UX:

- **HTML5**: Semantic tags to ensure strong SEO and web accessibility structure.
- **CSS3 (Vanilla)**: 
  - Harmonies of **Dodger Blue (`#1e90ff`)** and deep gradient tones for a unified brand style.
  - Alternating section backgrounds (`#ffffff` and `#f8f9fa`) for visual pace.
  - Custom fluid cards with elevation shadows.
  - Smooth micro-animations and state transitions.
- **JavaScript (Vanilla)**:
  - **Smooth Scrolling**: For navigation and layout transitions.
  - **Intersection Observer API**: Dynamic entry animations that fade/slide sections into view as the user scrolls.

## 🚀 Setup & Deployment

### Local Development
To run or preview this portfolio locally on your machine:
1. Clone this repository:
   ```bash
   git clone https://github.com/bzloh2/my_website.git
   ```
2. Simply double-click `index.html` or run a local server (e.g., using VS Code Live Server or Python):
   ```bash
   python3 -m http.server 8000
   ```
3. Open your browser and navigate to `http://localhost:8000`.

### Hosting on GitHub Pages
This project is set up with GitHub Actions under `.github/workflows/static.yml` for continuous delivery. Any changes pushed to the `main` branch are automatically built and published to GitHub Pages.
